SITE-BUSINESS — первый коммерческий шаблон

Как открыть:
1. Распакуйте ZIP.
2. Откройте папку в VS Code.
3. Дважды нажмите index.html или откройте его через браузер.

Основные файлы:
- index.html — структура сайта
- style.css — дизайн
- script.js — интерактивность
- images/ — фотографии клиента
